# HZ竞对监控-UI 规范 V1

版本：2026-11-08（已归并本轮用户确认的导航、边框、卡片及看板布局调整）。状态：8897 已接入共用主题与适配层；作为新增及改造页面的执行基线。以已确认的竞品货盘风格和日期范围组件为基础；本轮不改变业务规则、字段口径或接口。

## 1. 核心约束

1. 同类任务使用同一组件与状态来源。禁止同时保留原生控件和功能相同的注入控件。
2. 统一蓝色、中性浅底、紧凑工作台方向；不按页面另选主题。统计、设置、助手不能成为三种品牌。
3. 统一视觉语言，不强行统一业务布局。列表、看板、详情、配置、对话、帮助分别采用下述页面模板。
4. 二级菜单纯文字；一级分组可用统一线性 SVG。禁止 emoji 作为界面图标。
5. 按内容定宽，避免所有筛选平均铺满。日期范围使用「日历图标 开始日期 至 结束日期」一体组件。
6. 缺数据不能变成 0，不能显示 undefined/NaN/null 字面量。销量缺失不能由其他指标代替。
7. 共享 token 与组件是唯一来源；对第三方组件只做统一主题映射。禁止每个页面重新定义主色/字体/控件高度。

## 2. 视觉基础

### 2.1 色彩

| 语义 | V1 标准值 | 使用范围 |
| --- | --- | --- |
| 页面底色 | #F5F7FB | 全站工作区；不使用大渐变背景 |
| 内容面板 | #FFFFFF | 表格、表单、弹窗 |
| 轻背景 | #F8FAFC | 表头、键值信息、次级区域 |
| 页标题 | #203A57 | 页头和对象标题 |
| 正文 | #303133 | 表格、表单、说明 |
| 次级正文 | #5B667A | 字段标签、必要说明 |
| 辅助文本 | #606D7E | 时间、对象元信息；不可用浅灰承载必要状态 |
| 强调/主动作 | #1D6FD1 | 白字填充按钮、链接、选中态 |
| 装饰蓝 | #409EFF | 非文字指示线和装饰；不用于白字主按钮 |
| 选中背景 | #E8F2FD | 当前菜单、浅色选区 |
| 结构边框 | #DCE4EF | 表格及面板分隔 |
| 控件边框 | #D5DFEC | 默认浅灰蓝；聚焦时用主色强调，避免静态边框压过内容 |
| 成功 | #237A45 / #EFF8F2 | 已完成、已启用，带文字 |
| 警告 | #8A5700 / #FFF7E6 | 待处理、需关注，带文字 |
| 危险 | #C9363E / #FEF0F0 | 失败、删除、明确风险 |
| 中性状态 | #5B667A / #F0F2F5 | 未开始、无关联、不适用 |

保留用户确认的蓝色方向，但不机械复制低对比的色值。白字在现有 #409EFF 上的计算对比约 2.78:1，建议 #1D6FD1 约 4.95:1。本轮已接入共享主色，后续组件不得自行定义另一套主动作颜色。内部验收要求：普通文字至少 4.5:1，大字及焦点等必要交互状态指示至少 3:1；透明度、hover、disabled 分别检查。此处是本项目验收门槛，不是对全站已完成无障碍认证的声明。

平台色只用于平台身份，不代表成功失败。Shopee 采用蓝标签，Lazada 采用靛蓝标签；TikTok 可用中性标签。状态色与平台色不可互相替代。涨跌须同时给出方向和数值，风险色由业务风险定义，不能默认“涨=好/跌=坏”。

### 2.2 字体与信息层级

系统字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，不新增远程字体依赖。不在统计或设置页单独使用宋体、Georgia 等装饰字体。

| 层级 | 字号 / 字重 / 行高 | 限制 |
| --- | --- | --- |
| 页面标题 | 26px / 700 / 1.3 | 每个工作区一个；详情标题可两行 |
| 模块标题 | 18px / 600 / 1.4 | 子页/卡片标题不得大于页标题 |
| 分组标题 | 14px / 600 / 1.5 | 表单分组、表格区标题 |
| 正文/表格 | 13px / 400 / 1.5 | 重要对象名可 600 |
| 标签/辅助信息 | 12px / 400–500 / 1.5 | 不使用 10px 承载关键数据 |
| KPI 数字 | 32px / 700 / 1.1 | 销售看板紧凑卡片用 28px；不用于普通售价 |

数字列使用 `font-variant-numeric: tabular-nums`。普通价格采用正文色；数据精度保持业务口径，不能为了视觉统一擅自四舍五入。纯数字右对齐，名称和 SKU 左对齐，状态与操作在全站保持相同对齐方式。

既有英文眉题暂允许在货盘/日志保留兼容，下一轮统一页头时一并移除或收敛；新增页面不自行增加英文口号/章节编号。业务步骤编号允许保留。

### 2.3 布局、间距、圆角和层级

- 桌面左栏展开 168px，收起后不占宽度；左上角按钮切换并记住选择，刷新及跨页保持。二级菜单保持纯文字。页内容左右 28px。1280/1440/1600 宽度均需验收。
- 共用头部 64px 固定高，助手不单独改变高度。
- 900px 及以下使用导航抽屉，关闭时不占工作区；不得回退成 600px 高的纵向菜单。系统日志等新增入口必须在移动菜单可达。
- 基础间距取 4/8/12/16/24/32px；为兼容现有列表，筛选横向内边距 18px、页内边距 28px 作为具名例外，不随意创造其他值。
- 主容器圆角 14px，内区 8px，控件 6px，小标签 4px。一组信息通常只保留一层外边框，内部分组优先用间距和分隔线。
- 默认面板弱阴影或无阴影；弹层统一阴影。禁止用光晕和强渐变表达普通模块身份。
- 层级基线：内容 0、表内固定列 10、吸顶区 100、全局导航 200、下拉 300、遮罩/弹窗 400、通知 500；原生 dialog top layer 单独管理。禁止各模块随意使用 999x。
- 页面本身不得横向溢出；宽表只在表格容器滚动。窄屏控制组整体换行；复杂双月日期选择纵向堆叠。

## 3. 共用组件契约

### PageHeader / 页面头

左侧标题 + 一句业务说明，右侧主要页面动作。标题、菜单、面包屑名称一致。“在线列表”不在页面头变成“商品库”。无业务含义的 SS 徽章、深色 Hero、斜切形状不进入共用头。助手工作区可用紧凑标题，但共用外壳不变。

说明超过两行改为「查看口径」展开区，入口置于页面标题右侧；涉及模拟数据、来源缺失、操作是否实际生效的关键说明始终可见。

### FilterBar / 筛选

控件高 32px，标签 12px，与控件同行，组间距 12px，标签间距 8px；选项文字不被截成不可辨认的片段。按实际最长合理选项校核，超长选项通过菜单完整显示。

| 控件 | 宽度参考 |
| --- | --- |
| 站点 / 结果 | 80–96px |
| 平台 | 110–120px |
| 集团 / 主 SKU | 132–148px |
| 操作类型 / 销售员 | 148–168px |
| 店铺 / 部门 | 168–208px |
| 子 SKU 多值 | 180–220px |
| 日期范围 | 280–300px |

宽度是组件规格，不是平均列宽。常用筛选放前两行；第三行起可折叠为「更多筛选」，但须显示已启用条件数量。查询与重置保持同组并右对齐，窄屏可自然换行。不把清空按钮做成一整列宽。

常用排列：平台 → 站点（适用时）→ 集团 → 部门 → 店铺 → 销售员 → 业务类型/状态 → 主/子 SKU → 日期范围。字段适用性由业务决定，不强加不存在的维度。切换上游组织需清理无效下游值；查询后页码回到 1；重置恢复文档化默认值。

**一个字段、一个控件、一个状态源**。已有原生字段时应迁移/复用，不能再注入第二套。创建时间与添加时间若含义不同，应明确写出对象与来源，不能先凭视觉去重导致业务信息丢失。

### DateRange / 日期范围

单边框、日历图标、开始日期、至、结束日期、清空。选择起止日期后关闭日历；支持键盘输入和月份切换，按 Esc 关闭并返回触发控件；点击外部关闭。范围内日期有浅色填充，端点有实心选中态。

系统日志为北京时间日期口径：起始日 00:00:00 到结束日 23:59:59，包含两端；非法日期、反向范围有就近错误提示。若业务需要精确时分，显式使用另一个 DateTimeRange 变体，不用两个独立原生框临时拼装。

### Button / 动作

- 同一操作区最多一个高强调主动作；查询/新增/保存为蓝色主按钮。
- 次要动作用白底描边；详情/编辑可用文字按钮；危险动作用红色且文案明确。
- “分析”不是危险操作，不用红色实心。异步分析在执行中禁用重复提交并显示处理中。
- 普通按钮 32px；桌面表格行内紧凑动作可 28px；触屏命中区域至少 44px，可通过额外 padding 实现，不要求桌面行高全部增加。
- 默认、hover、focus-visible、按下、禁用、加载、错误、成功均有可预测反馈。只有适用状态才进入该组件，不为静态标签添加无意义动画。

### DataTable / 表格

列表外围容器不显示卡片边框或描边阴影；保留白底、原有圆角和内边距，通过留白、表头底色及行分隔线组织内容。嵌套列表不得再叠加一层包围式描边。此规则覆盖货盘、在线列表、内容/价格报告、日志、今日必办，以及统计和设置中的列表；不移除输入框边界、焦点提示、表格内部分隔线、指标卡或弹窗边框。

表头 40px；纯文本行建议 48px；商品多行摘要行建议 72–96px，不能靠裁切重要文本硬凑行高。表格宽度由内容决定。

竞品货盘页头说明至筛选区的最终间距为16px，不叠加页头底边距。操作列实际渲染宽度180px；第一行详情/编辑竞对/分析，第二行历史报告/停用或启用；验收实际列宽，不只检查CSS声明值。

**左侧固定商品信息，右侧固定操作栏**。商品类列表将主图（如有）、商品名称和主/子 SKU 等识别信息作为左侧固定列组，不能仅固定图片而让名称、SKU 滚出视野；详情、编辑、分析等行级动作固定在右侧。中间业务字段在表格容器内横向滚动，固定相对于表格可视区，不固定到整个浏览器窗口。非商品类列表左侧固定对应对象的关键识别信息；没有行级动作时不新增空操作栏。

固定列表头与单元格使用一致的列宽和偏移，保持上下对齐；背景不透明，选中/悬停状态与当前行一致。分隔线或轻微侧向阴影仅用于标识固定区边界，不恢复列表外围卡片描边。固定区域不得彼此叠压，也不得盖住中间字段或行内按钮；窄屏使用紧凑信息及动作布局，确保中间字段仍可滚动查看、全部操作可达，不通过隐藏商品标识解决空间不足。

**操作栏使用超链文本形式，删除用红色**。行级动作不使用填充底色、按钮描边或大块内边距；常规动作用主色文本，删除用危险红，悬停加下划线，键盘焦点清晰。多动作采用紧凑间距并允许有序换行；保留禁用、加载及确认状态。此约定不改变筛选区、页面工具栏及弹窗主按钮的层级。

**页面跳转打开新标签，不覆盖当前列表**。详情、报告、历史报告及进入独立编辑页面的入口均适用，保留当前筛选、页码与滚动位置；保留原目标对象及查询参数，新页面不持有来源页的 opener。链接具备明确目标地址时使用原生链接语义。编辑弹窗、删除、启停等原地操作继续使用对应弹窗/确认流程，不另开空白标签；需要确认后进入分析页的操作，确认后再新开标签，取消时不跳转。将来新增列表沿用该交互契约。

商品标题最多两行，SKU 独立一行，组织/店铺为次信息。必要长文本支持点击展开或键盘可达的完整内容，不只靠 hover。同类对象列在不同列表使用同一单元格组件。

分页统一底部：总数、页大小、当前页、前后页。表格空态、加载、错误不复用同一句“暂无数据”；有筛选空态必须给重置入口。

### StatusTag / PlatformTag

小标签统一高约 20px、字号 12px、圆角 4px；不把正常状态做成巨大胶囊。平台固定大小写 `Shopee` / `Lazada` / `TikTok`，有站点用 `Lazada · TH`；不根据商品文字猜平台，使用结构化字段。

状态文案至少区分：未开始、处理中、成功、失败、结果未确认、未同步、不适用。已接受建议与执行成功分开，日志不得省略该差异。低对比灰字不能作为唯一状态提示。

### Detail / 对象详情

返回入口 → 对象摘要 → 核心档案 → 页签 → 业务明细。摘要有图时使用同一规格，无图使用中性缩写占位，不给每种对象另造品牌块。

详情标题 26px、最多两行；档案使用定义清晰的键值网格，未知值为 — 并附原因。数据为空时先判断业务缺失、未同步、加载失败，再显示对应解释；严禁直接拼接 `¥undefined` 或 `undefinedkg`。

### Dialog / Drawer / Tooltip

确认弹窗宽 480px，普通表单 640px，日志/复杂详情 720px；最大不超过 `viewport - 32px`，内部滚动，标题/页脚固定。弹窗标题 20px，关闭按钮位置一致。焦点进入弹窗、Esc 关闭（可取消时）、关闭后回触发点；不能被原型工具入口盖住。

小量编辑用弹窗，持续对照列表用侧抽屉，复杂对象使用详情页。信息提示采用统一图标、颜色、字号；必要信息必须可点击/聚焦打开，不仅 hover 可见。

### ImportDialog / 导入弹窗

竞品货盘与在线列表使用同一导入视觉模板：桌面宽 800px，最大宽度为视口减 32px，圆角 14px；桌面距顶部 5vh、最大高 90dvh，窄屏四周至少 16px。标题 20px，标题与说明左对齐；内容区内滚动，页头及底部动作始终可达。

- 使用下划线页签，蓝色选中态；货盘保留子 SKU / Item 的单个与批量四种入口，在线列表保留单个新增 / 批量导入两种入口，不为统一外观改变业务范围。
- 批量导入统一呈现「01 下载并填写模板 → 02 选择填写好的 Excel 文件 → 校验/导入结果」。步骤序号为蓝色浅底，说明区使用中性浅底，不使用独立绿色主题或渐变。
- 控件与按钮高 32px、圆角 6px，输入框浅边框 #D5DFEC；分组间距 16px、组内间距 12px。文件名在选择后可见，长文件名可换行，不撑出弹窗。
- 取消及当前步骤主动作在底部右对齐。货盘单个录入的「校验导入」进入底栏，校验成功后切换为「确认导入有效行」；批量文件自动校验后展示有效/失败行。在线列表沿用现有提交与结果反馈，不混淆校验成功和实际导入成功。
- 必填项、平台/站点一致性、模板字段、逐行错误、去重和竞对继承规则按各自业务保留；不以统一视觉为由删除说明或伪造成功状态。
- 验收单个/批量切换、模板下载、文件选择、失败与结果、取消/关闭、键盘焦点；1440px/1280px/390px 下弹窗、页脚和表格滚动均可用。

### Empty / Loading / Error

- 无结果：没有符合条件的记录 + 重置筛选。
- 未采集/未同步：写清来源及后续可执行动作，不伪造数字。
- 加载中：稳定布局的骨架或延迟出现的 loading，不让整个页面闪动。
- 请求失败：保留已输入条件，提供重试；不冒充空结果。
- 操作成功：结果已在界面可见时避免重复庆祝提示；长任务完成或失败提供明确反馈。

## 4. 页面模板

| 类型 | 结构 | 允许差异 |
| --- | --- | --- |
| 列表 | PageHeader → FilterBar → 表格/分页 | 商品摘要行、日志文本行可不同密度 |
| 看板 | PageHeader → 全局筛选 → 核心指标 → 趋势/任务 | 图形与指标布局允许变化，字体和语义色不变 |
| 详情 | 返回 → 摘要 → 档案 → 页签 | 字段、图表和业务操作按对象变化 |
| 配置 | PageHeader → 一层业务页签 → 分组表单 | 分组内独立保存，但不再套大 Hero |
| 助手 | 共用外壳 → 会话列表 → 对话/输入 | 保持专用工作区，不强套表格页 |
| 帮助 | PageHeader → 目录 → 正文/步骤 | 目录导航和业务步骤保留，长文行宽受控 |

### 4.1 销售看板 / 已确认页面规范

页面顺序：页头 → 本期运营说明 → 六张指标卡 → 今日必办。以下为销售看板专属约定；其他页面复用组件基础，不自动套用业务分类的显隐规则。

| 区域 | 执行规范 |
| --- | --- |
| 页面头 | 左侧「销售看板」，右上角文字入口「查看统计口径」，与标题同行；不单独占用卡片下方一行 |
| 口径展开 | 点击展开原统计说明，再次点击收起，按钮同步改为「收起统计口径」；展开状态可由键盘及辅助技术识别 |
| 标题与说明 | 页头和「本期运营看板」说明之间的最终间距为 16px；不得叠加标题 margin 与父级 gap 撑大间距 |
| 区块间距 | 说明、指标区、今日必办之间采用 16px；指标卡之间采用 12px |
| 紧凑指标卡 | 保留六张卡片与完整数据；仅一层内边距，上下 14px、左右 16px；内容最小高 118px，含边框常规约 120px；数字 28px |
| 卡片内容 | 长说明自然换行并允许卡片增高；不以裁切文字、隐藏说明或改变数据精度来压缩高度 |
| 今日必办页签 | 「价格异动」「竞对动态」从左侧起排列；沿用实际名称「价格异动」，不另增同义的「今日异动」页签 |
| 今日必办筛选 | 平台筛选排在页签之后，桌面靠右；窄屏换到下一行左侧，键盘顺序与视觉顺序一致 |
| 今日必办隐藏项 | 隐藏「待补充 URL」与「货盘系统新增」（需求中称「货盘新增」）分类；隐藏范围仅为今日必办页签，不删除上方指标卡、统计值或底层数据 |
| 选中状态 | 若原选中项被隐藏，切回「价格异动」；页签切换、刷新、返回页面后不能停留在无可见入口的分类 |
| 配套文案 | 今日必办的说明与当前可见分类一致，不继续提示已隐藏分类的处理优先级 |
| 价格异动身份 | 平台与站点合并显示，销售员另行；不再重复单列站点 |
| 价格异动金额 | 本币主金额＋同行灰色人民币参考金额，例如 THB 189（≈¥37.12）；我方最低价与更新时间并入货盘信息，跟随中文名称和子 SKU 展示；缺值保留未知，不补0 |
| 价格异动层级 | 保留竞对类型标签和涨跌幅，规格/采样时间作为辅助信息；竞品最新价、涨跌幅、在线利润率统一放在竞品信息表头并与行内值对齐，行内不重复指标标签；“查看报告”使用单行文本操作，未生成报告保留不可用状态；报告失败和无法定价原因仍需显示 |

窄屏仍保留页头右侧口径入口和两个可见页签；宽表在自己的容器内横滚，不使整个页面横向溢出。

### 4.2 统计看板 / 筛选顺序

- 核心周报：日期 → 平台 → 站点 → 集团 → 部门 → 销售员 → 更新周报。
- 运营动作：统计周期 → 平台 → 统计维度（集团 / 部门 / 销售员）→ 更新看板。
- 平台紧邻站点或统计维度之前，不插在说明文案之前，不用自动伸展把平台与后续条件拉开。
- 按可用宽度自然换行；两个页签的平台选择保持联动，保留原查询行为和数据来源说明。

## 5. 落地约束

1. 先指定单一规范文件和组件归属，后迁移页面；本文件优先于旧技能中通用橙色主题等非项目专属建议。
2. 原型可先新增集中 tokens 和共用适配组件；正式源码应在现有 Vue/Element Plus 层建立组件，禁止为视觉统一重建整站或修改路由业务。
3. 不直接批量改 minified bundle。先找到源码归属；暂时只能维护原型时，增量适配层须可回退、有幂等检测、有明确路由范围。
4. 删除重复控件前核对字段语义、事件、状态与接口参数；不能只隐藏其中一份并保留冲突更新。
5. 生效变量为 `prototype/hz_online_20261105/hz-ui-tokens.css`；组件映射为 `hz-ui.css`，共用交互为 `hz-ui.js`。修改规范与变量必须同步。
6. 多平台导入已独立完成并上线。本轮保留其按 Item 下子 SKU 分别建货盘的行为；发布清单只包含当前批次文件并先备份。
